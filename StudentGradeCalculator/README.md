# Student Profile & Grade Calculator
## Description
A console application written in Python to manage
student information and calculate grades.
## Features
- Add student information
- Add grades (0-100)
- View all grades
- Calculate average grade
- Show highest and lowest grades
- Determine grade category (A, B, C, D, F)
- Show Pass/Fail status
- Validate user input
## Technologies
- Python 3
## How to Run
1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the command:
python main.py
